Install

Three steps

  1. Download the APKYour download starts after the countdown. If it does not, tap Download APK.
  2. Allow installs from this sourceAndroid asks once. Tap Settings, then turn on Allow from this source.
  3. Open the file and tap InstallIf Play Protect warns about an unrecognised app, tap More details, then Install anyway.
Why the warning The app is not on the Play Store, so Android shows a standard caution for any app installed from a file.
